# SubFleet

部队工房潜水艇作业插件（FF14 国服 / XIVLauncherCN，API 15）。

这不是 SubOps 的续作，是照着 **DailyRoutines 的 `AutoSubmarineCollect`** 重新写的：
流程一样、读法一样，只是把它的 TaskHelper 换成了一个小的顺序任务队列。

## 一次收取做什么

```
传送到部队房屋 → 进屋 → 选「潜水艇工房」→ 开航行管制面板 → 选「管理潜水艇」
  → 列表里点一艘已返航的 → 单艘艇菜单：先「上次的远航报告」，再「出发」
  → 远航报告：点「再次出发」（callback 0）——收下奖励并打开出航确认页
  → 出航确认页：读 4 个零件，耐久为 0 的全部修好（RepairSubmarinePart 1153）
  → 点「出发」→ 等 2 秒 → 回到列表
  → 还有待收的就继续，没有就退出
```

两个关键数字（用 `/sf debug` 或日志可复核）：

- 远航报告窗口：左边「再次出发」= callback **0**，右边「确认完毕」= callback **1**。
  点 1 只会收下奖励、**不会**打开出航确认页——这就是「收过了却从不出航」的根因。
- 「选择航海图」（`AirShipExploration`）出现＝这艘没有可复用的上次航线，
  插件不猜航线，只退出去重走「报告 → 再次出发 → 出发」，退不掉就跳过这艘。

## 多角色

- 每个角色登录一次就会自动进名册（`/sf char` 查看）。
- **名册顺序 = 轮换顺序**。窗口里每行前面有 ↑ ↓ 按钮可以上下挪；还有两个一键按钮：
  「按返航时间排序」（返航近的靠前，没进过工房的排最后）、「当前角色置顶」。
  轮换正在跑的时候排序也安全——游标会跟着原来那个角色走，不会漏人也不会重复处理。
- `/sf sweep` 从名册第一个开始，收完切下一个；需要装 **Lifestream**（走它的 IPC 切号）。
- 某个角色失败（切号超时 / 传送失败 / 收取失败）会打 30 分钟冷却跳过，不卡整轮。
- 名册和进度会存进配置，插件重载后能接着跑。

## 浮动图标

屏幕上有个小方块「艇」，不用进卫月插件设置就能开关主窗口：

- **左键**：打开 / 收起主窗口
- **右键**：直接开始收取当前角色
- **按住拖动**：随便挪，位置记在配置里，下次登录还在那
- 颜色：绿＝正在收取，蓝＝轮换中，深灰＝待机
- 不想要了：主窗口最下面取消勾选「显示浮动图标（可拖动）」

## 命令

| 命令 | 作用 |
|---|---|
| `/subfleet`、`/sf` | 开关窗口 || `/sf run` | 只收当前角色 |
| `/sf sweep` | 开始多角色轮换 |
| `/sf stop` | 全部停下 |
| `/sf status` | 一句话状态 |
| `/sf char` | 列名册 |
| `/sf debug` | 打印现场：工房内/房内/庭院、部队房屋、青磷水与修理材料、游戏内潜艇下标、4 艘艇的返航时间与零件耐久、当前开着的窗口 |

`/sf debug` 是排障主力：卡住的时候先跑它，日志里同时会写 `[SubFleet]` 开头的记录。

## 几条硬规则

- **靠过去只落一个点**：直接落到目标坐标上（DailyRoutines 也是 TPSmart 到门口再交互），
  判定距离留 0.4 米余量、用带高度的距离。以前落点正好压在判定线上，
  加上浮点误差就会「永远差那么一点」，于是每三拍换个 90° 方向重来 —— 表现就是围着房子左右弹。
- **瞬移落不下去要认**：连续 3 次没站住就停手，连续 9 次直接报「到不了房屋入口/面板」并说明当前坐标，
  不再靠 6 分钟的步骤超时兜底。
- **修好才出发**：零件读不到就等（15 秒），等不到就跳过这艘，绝不盲点「出发」。
  宁可少派一艘，也不要出现「点了出发却出不了港，还把这一艘记成已处理」。
- **该收哪艘只看返航时间**，不看「点过什么」。
- **已经在面板前就只交互，不再瞬移**；瞬移只在超出交互距离时发生，落点只在同一层地面。
- **确认框里含「离开」一律点「否」**，进屋不会又自己跑出去。
